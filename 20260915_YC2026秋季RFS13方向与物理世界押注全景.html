一分钟速览

  1. 全球最有名的创业孵化器 YC（Airbnb、Stripe 都出自这里）公布了 2026 秋季「创业征集令」，一次列出 13 个它最想让人去做的方向，还特意说明「不做这些也照样能申请」。
  2. 这一批有个统一主题：AI 从屏幕里走出来，进国防、养老、工地、海洋这些真实世界的场景；纯生成式 AI（文生图、文生视频、模型本身）这次几乎缺席。
  3. 史上第一次，有一条方向是现任美国陆军部长亲自写的：他公开向创业者要低成本拦截器、要能插进军队开放架构的无人机传感器，目标是把「每次击杀的成本」打下来。
  4. 为什么押在现在：智能刚好够用（可以把 Agent 当成一个人来使唤），而成本正每年降 10 倍，YC 判断消费级的引爆点就在眼前。
  5. 对创业者，这是一张现成的选题地图；对所有人，这是「全球顶级孵化器 2026 把钱往哪押」的官方风向标。
这是什么

02先搞清楚 YC 这份清单是什么

每隔一阵，YC 就会公开一张清单，写明它最想让人去做的创业方向。2026 年秋天这批有 13 条，主题只有一个：让 AI 从屏幕里走出来，走进真实世界。

这张清单叫 RFS（Requests for Startups，直译「创业需求列表」，也就是一张「征集令」）。YC 是全球最有名的创业孵化器，Airbnb、Stripe、Coinbase 都是从这里走出去的。它把自己最想看到有人去做的方向列出来，等于告诉创业者：你要是在做这个，来找我们，钱和资源都有。

YC 也把话说在前头：列出来只是想让人知道我们在想什么，哪怕你一条都不做，照样能申请。所以这张单子不是命题作文，更像一份风向标：顶级机构愿意把钱往哪儿投，本身就是信息。

▸这一批最反常的一条

13 个方向里，有一条的作者身份不同寻常：现任美国陆军部长 Daniel Driscoll（第 26 任，2025 年 2 月上任）亲自写的。一个政府高官跑到创业孵化器的页面上发招标。这在 YC 的历史上还是头一回。

核验补注 YC 官方 RFS 页面开头亦明确写道：「for the first time, one from the sitting U.S. Secretary of the Army」（首次由现任美国陆军部长撰写的一篇 RFS），与上述判断一致。

主线

04为什么这一批全在讲物理世界

把 13 条连起来看，一条主线就浮出来了：过去几年，AI 的战场几乎都在屏幕里：写代码、生成文字和图片、在聊天框里答问题。这一批，YC 把筹码押到了屏幕之外。

国防、把算力搬上海、给工地做操作系统、采集物理世界的数据，这些都得跟硬件和线下场景硬碰硬。就连消费和社会那几条也带着强烈的线下味：养老离不开家里的监护和机器人，教育对着的是真实的孩子，「证明你是人」要解决的正是线上线下都在崩的信任。

▸一个值得注意的缺席

这一批里，纯生成式 AI（做文生图、文生视频、或者模型本身）几乎一条都没有。占大头的是难啃的物理世界和面向企业的基础设施。做模型、做生成工具那波最热的方向，这次没被单列。这本身也是一种信号。

头条 · 教育

05让 AI 像私教一样教小孩

这一批的头条方向，作者借了一本书来说。科幻小说《钻石时代》里有一本会「因材施教」的魔法书，叫《一位年轻女士的图文启蒙读本》。它看着是本识字书，实则远不止：它完全围着一个女孩转，用贴合她生活的故事，不只教她认字，还教她思考、推理，陪她长大，她长成什么样，书也跟着变成什么样。

▸这条方向的内核

最好的教育，从来都是一对一的私教。亚里士多德教亚历山大。但这份待遇，历来只属于极少数人。AI 第一次让「给每个孩子配一个私教」这件事，在原理上成了可能。

好的私教厉害在哪？不只是陪着刷题。它花上几年时间摸清一个孩子的脑子怎么转，然后教那些刷题刷不出来的东西：怎么思考、怎么推理，甚至怎么变得有智慧。今天的教育软件差的正是这一截：

今天的教育软件
  • 统一进度、统一题库
  • 本质是电子版的刷题和抽认卡
  • 不认识你的孩子是谁
YC 想要的 Primer
  • 像私教一样因材施教
  • 教读写算，做到私教的质量
  • 随孩子成长而变，是老师的补充不是替代

YC 说得很实在：离真正造出《钻石时代》那本书还很远，但今天可以先起步。它现在想要的，是一个能像尽心私教一样、教小孩读写算，又能做到消费级价格、人人用得起的产品。

它一开始会是家长掏钱、给孩子补基础技能的小东西。但这只是入口。做对了的公司可以一路往那本魔法书的方向长。哪怕只实现了那个愿景的一小部分，对整个社会的影响也会很深。

新闻 · 国防

06陆军部长直接来要东西

13 条里最反常的一条，来自现任美国陆军部长 Daniel Driscoll。他给出的理由是：战争正处在拐点，而军队老一套的采购流程，跟不上今天变化的威胁。所以他们「撕掉了旧的采购剧本」，直接跑来向创业者要东西。

现代战争要的是商业化开发、模块化的开放系统方案，这正是我们撕掉旧采购剧本的原因。

Daniel P. Driscoll，美国陆军部长

他要的东西很具体，也第一次把军费的算盘明明白白摆到了创业者面前：

  • 低成本拦截器用便宜的东西拦下敌方目标，把「每次击杀的成本」压到最低，或者任何能帮着压低这个成本的部件
  • 能插进开放架构的软硬件下一代传感器、软件、载荷等硬件，要能直接接进军队的开放系统架构
  • 抗极端气候的装备前沿无人机、有韧性的后勤、先进制造，还得在从北极到群岛、从太空到地下的极端环境里撑得住
  • 承诺：给钱 + 给试验场「把你的想法带来，我们给你资本，也给你可以放手扩产的练兵场」

▸这里有两个词值得先讲明白

低成本拦截器 / cost per kill（每次击杀的成本）
敌方的无人机可能很便宜，你不能每次都用一枚天价导弹去换。所以军方要的是用尽量低的花费拦下一个目标，把这笔单价打下来。
模块化开放系统架构
军方不想被单一供应商锁死。他们要装备像搭乐高：接口是开放的、零件能随时换、新东西能直接插进去，而不是买一整套黑箱。
最大胆 · 算力

07把数据中心搬到海上

这条乍听最反常，但顺着逻辑走下去，其实不难懂。起点是一个真实的瓶颈：AI 快没算力了，而数据中心快没电、没地了。

问题出在陆地上盖数据中心：审批要拖好几年，还得凑够足够的电，最后可能因为一句地方政府的反对就黄了。社区越来越抵触占地、占水。但有一片地方一直是敞开的，那就是海。

消费与社会

08消费和社会，押了这三件

除了教育那条头条，消费和社会这一类还有三个方向。它们的共同点是：面对的都是天大的市场，却一直没被好好服务。

每次平台大迁移都会诞生消费巨头：Web 出了 Google，移动出了 Instagram。可 AI 都三年了，你手机上唯一的新图标还只有 ChatGPT。

为什么是现在？智能刚好够用（可以把一个 Agent 当成一个人来使唤），而且马上会足够便宜：今天让这套魔法跑起来，每个用户每月要烧约 1000 美元 token，但这个数字每年降 10 倍。顺着曲线往下推，消费级的引爆点就要到了。谁现在动手，谁占住。

2030 年，每 5 个美国人就有 1 个超过 65 岁，照护的人手远远不够，护理岗位缺口以百万计，已经有 5300 万家人在无偿干这件事。可几乎没有真正为老人做的科技，连 Alexa、Google Home 老人都用得一头雾水。

前不久，一名财务人员参加了一场和「CFO 及几位同事」的视频会，会后转出了 2500 万美元。事后才发现，那场会里除了他自己，每个人都是 deepfake（AI 换脸换声）。声音克隆和假视频通话正变得又便宜又逼真，这类诈骗在暴涨。

吓人的地方在于：我们已经没有好办法判断对面是不是真人了。过去「看见脸、听见声」就够，现在不够了。所有信任信号，都是在「假冒一个人很贵」的年代建起来的，那个年代已经过去。YC 要的是重建互联网的信任层：知道电话、消息、交易那头是一个验证过的真人，最好还不用大家交出隐私。谁做成，谁就成了每家银行、每个 App、每通视频在信任谁之前都要先查一下的那一层。

物理世界 · 续

09物理世界还剩两条

回到物理世界这一类，除了国防和海上算力，还有两条对着「线下的活」和「真实的数据」。

全球 80% 的劳动力不坐办公室。可工地、维修、车队用的软件 20 年没大变，翻来覆去就是那几件事：派活、追踪人、管资产、给客户开账单。

AI 把这套彻底改了。现在工地上有了三种工人：会报价、会排班的 AI Agent；真的下场干活的机器人；以及戴着可穿戴设备、把一切都记录下来的人。老软件从来不是为「同时管这三种工人」设计的。一份活该派给 Agent、机器人还是人？人和机器人肩并肩干活时安全怎么算？这些全是新机会。而且这些行业花在人力上的钱，是花在软件上的 10 到 100 倍。

AI 学软件、语言、图像的数据已经练到超人水平，但物理世界的数据还很稀：我们还在用一堆为人（不是为 AI）设计的遥感器采集零星数据。

随着基础模型变强、传感器越来越便宜，稠密采集物理世界数据第一次变得可行。有人用机器人去人到不了的地方采数据、建预测模型；作者自己的公司 Sorcerer 则用自主气象气球采集大气数据，美国政府拿它来改进天气预报。能源、农业、物流、建筑这些最大的行业，至今还靠有限数据和拍脑袋的经验。数据够密就能建模，能建模就能控制。

软件基建

10软件时代要补的四块地基

还有一整类方向，是给 AI 时代的软件补基础设施，都是「现在做起来突然变得可能、以前不值得做」的活。

▸小软件的云

用 Agent 给自己造一个只有一两个人用的小工具，现在很容易也很好玩。可造出来之后，部署和分享还是很难。AWS、Azure 这些云是为「能扛很多用户的大软件」设计的，代价就是复杂。

一朵专为小软件设计的云，能砍掉大半复杂度，让分享一个小工具，像分享一份 Google Doc 一样简单。当然也有硬骨头：每家公司都想定制运行环境，权限和鉴权很难，让不懂技术的人安全地分享任意代码也很棘手。

▸多人协作的 AI

过去 20 年最好的工具都靠「多人化」赢：Google Docs 干掉了 Word，Figma 干掉了 Photoshop。可 AI 至今还是单人游戏：你开个聊天框、发个 prompt、答案在一个只有你看得见的框里。想跟同事一起用，最多发个只读记录的链接。

当 Agent 开始跑几小时、几天甚至几周的长任务，这种活本就不该一个人干。团队里任何人都该能随时进同一个 Agent 会话，看它干、给它纠偏、把活接过来，就像跟一个人类同事协作那样。工程、销售、客服、法务、分析、市场，凡是一群人围着一个问题的地方，都该有个大家共享的 Agent。

▸AI 原生的合规基建

金融合规到今天还是靠 Excel、一堆各管一段的工具、外加高薪养的人硬堆出来的。公司请首席合规官、拼一摞点状工具，就为搞清楚「底下到底在发生什么」。业务一扩张到新市场，复杂度翻倍，合规成本涨得比营收还快。

可合规的大部分工作（盯着监管变化、标出异常、生成报告、留审计痕迹）恰恰是 AI 干得又快又便宜的活。最好的版本不只是把现有流程自动化，而是重新想象「当 AI 是默认劳动力时，合规该长什么样」。跨州牌照、续期、审计这类最零碎的地方，痛点也最集中。

▸自我维护的 API

作者过去一年跟 50 多家 API 供应商打过交道，发现一个通病：API 之间的「沟通」是坏的。破坏性变更几乎没预警就上线，有用的新功能悄悄发布没人注意，changelog 没人读。他在 AWS 时，超过 30% 的服务宕机，是外部 API 或依赖包变了却没人察觉造成的。

既然大家已经愿意把代码库权限交给 Claude Code、Devin 这类工具，那 API 提供方就不该只「通知」你有变更，该直接把变更给你应用上。Stripe 一发布破坏性改动或新功能，就该有个 Agent 扫一遍客户代码、找出受影响的地方、开好一个修复 PR。可以是每家自带的更新 Agent，也可以是一个跨供应商的中立服务，像「API 界的 Dependabot」。

加密

11为什么现在是建加密的最好时机

最后一条最反直觉。现状确实不好看：币价跌、热门叙事一个个哑火、不少人正在离场。可 YC 说，他们比以往任何时候都更看好。理由和价格无关，全看谁还留在场上。

牛市 · 最差的建设期
  • 价格和现实脱钩，泡沫喧嚣
  • 要跟「提供无限收益」的骗子抢用户
  • 吸引来的是冲着套现来的人
熊市 · 真项目才活得下来
  • 没人跟你抢，能安心打磨
  • 留下的是更想做事、不急着套现的创始人
  • 监管终于清晰，稳定币被大机构采用

YC 说它已经投了 100 多家加密公司，还预期这个数字会大涨，它甚至判断，未来几乎每家 YC 创业公司都会用上加密的底层管道（从融资到收付款），只是大多数人自己都不会察觉。它点名看好的方向包括：融资、新的稳定币及其应用、Agent 直接用加密网络当金融管道、交易、面向机构的产品，以及可扩展又保护隐私的区块链。

12这份清单，你该怎么读
